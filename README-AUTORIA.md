# Sobre el código y su autoría

El nombre `useQuery` es habitual para un hook que consulta datos y no demuestra quién escribió un archivo. La estructura o el estilo de un proyecto tampoco permiten garantizar que algo «parezca» o no generado con IA.

Esta actualización tuvo asistencia de IA. No se puede afirmar lo contrario ni certificar la autoría de los archivos anteriores a esta revisión. Antes de entregar el proyecto, revisa el código, comprende su funcionamiento y declara la asistencia según las reglas de tu curso.
